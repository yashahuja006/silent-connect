# Silent-Connect 🤟

**A revolutionary Universal AI Platform featuring advanced voice-controlled hand gesture recognition, IoT control, health analytics, and custom AI training - designed to excel across multiple hackathon tracks.**

## 🎯 Project Overview

Silent-Connect is an innovative web application that transforms hand gestures into actionable intelligence across multiple domains. Built with cutting-edge MediaPipe technology and React, it provides real-time hand tracking with applications in communication, IoT, healthcare, education, and AI training.

**🆕 UNIVERSAL MODULES: Now supporting 5+ hackathon tracks with specialized modules for IoT, HealthTech, Education, Innovation, and Accessibility.**

**🔊 NEW: Advanced Voice Control System with Male/Female/AI voice options and speech toggle controls.**

**🚀 NEW: High-Performance Mode supporting 60-90 FPS for ultra-smooth gesture tracking.**

## 🚨 Troubleshooting

### Common Issues

**Camera not working:**
- Ensure HTTPS connection (required for camera access)
- Grant camera permissions in browser
- Check if camera is being used by another app
- Try refreshing the page

**Gestures not recognized:**
- Ensure good lighting conditions
- Position hand clearly in camera frame
- Hold gesture steadily for 800ms (reduced from 1 second)
- Check confidence meter reaches 55%+ (lowered threshold)
- **Fist Issues**: Try making a tighter fist - new 5-method detection is more accurate
- **Thank You Issues**: Position hand in center of screen at moderate height

**Module-specific issues:**
- **Smart Home**: Check gesture mappings in instructions
- **Health Analytics**: Ensure hand is visible for data collection
  - **0% Stability Fix**: New algorithm shows 10-100% range immediately
  - **Slow Updates**: Now optimized to update every 5th frame for better performance
- **AI Training**: Verify gesture is held steady during capture
- **Charts not loading**: Ensure recharts is properly installed

**Performance issues:**
- Close other browser tabs
- Ensure hardware acceleration is enabled
- Use recommended browsers (Chrome/Edge)
- Check internet connection for CDN resources
